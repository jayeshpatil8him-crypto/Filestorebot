# Telegram File Store Bot

A production-ready Telegram bot for storing and sharing files with advanced features.

## Features

- **Permanent File Storage**: Store files with metadata
- **Batch Link Generator**: Generate encrypted links for multiple files
- **Force Subscribe System**: Require users to join channels
- **Auto Delete**: Auto-delete files after configurable time
- **Sudo System**: Admin hierarchy
- **Broadcast**: Send messages to all users
- **Rate Limiting**: Prevent abuse
- **Full Asynchronous**: Fast and efficient
